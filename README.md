# お手伝いクエスト（homework-quest）

宿題・お手伝いを自分でチェックして進める一人用アプリ。
達成すると **ポイント → レベルアップ／バッジ** で達成感が出て、頑張りは
**カレンダー・連続日数（ストリーク）・グラフ** で見える化します。

**公開URL**: <https://yu-ichi7.github.io/homework-quest/>
（GitHub Pages 配信。PCやサーバー不要で、いつでもどこからでも開けます）

- 一人用。チェックしたら即ポイント確定（承認フローなし）
- 定番ルーティン（毎週この曜日）＋スポット（この日だけ）の両対応
- **デイリーボーナス**… 毎日「今日」画面のギフトボックスをタップすると受け取れる。
  連続日数が伸びるほど基本コインが増え（最大14日で頭打ち）、おまけコインが出やすくなる。
  7・14・30…日の節目には特別ボーナスも
- 貯めたポイントは **コイン** として消費でき、「ゲーム」で使える:
  - **シューティング**… 昔ながらの縦スクロールSTG。🪙30で出撃し、**全画面**で遊ぶ。
    操作は画面を指でなぞるだけ（**前後にも動ける**／弾は自動）。**敵も弾を撃つ**ので避けながら戦う。
    **敵の種類は4タイプ**（ふつう・かたい・すばやい・狙撃）、ステージが進むほど多く出現。
    **5ステージ**各々に異なるボスがいて、ステージごとに背景テーマも変わる。ボスを倒すとステージ制覇で1プレイ終了、
    次のステージが解放される。敵が落とすアイテム（💥⚡❤️）でさらに強くなり、
    永続強化（ショット強化・連射速度・ライフ）もコインで買える。ハイスコアが記録される
    - 敵タイプ：ふつう（序盤主体）、かたい（かたく・遅い）、すばやい（速く・左右に揺れる・レア）、
      狙撃（中速・自機を狙って弾を撃つ）
    - 得点は **ステージの満点 × 進み具合 −（被弾ごとの減点）**。
      **ノーミスでクリアするとちょうど満点**になる（第1面 10000／第2面 12000／第3面 15000／
      第4面 18000／第5面 20000）。被弾1回につき満点の8%が減る
    - 背景が毎ステージ異なる（緑の草原→雲の海→稲妻の谷→炎の火山→宇宙要塞の5つのテーマ）
      ため、手ごたえと視認性がステージの難度を表現する
    - 出撃前に **体当たりアイテム**（🪙10/個・最大5個）を買える。体当たりした敵をノーダメージで倒せる
    - 永続強化に **護衛機**（🪙500/体・最大3体）を追加。自機の周りを等間隔でくるくる回りながら自動で弾を撃つ
  - **ペット**… ピンク／オレンジ／あお の子を1体育てる、たまごっち系の育成ゲーム。
    ごはん・あそぶでお世話し、あかちゃん→少年→成体と進化。お世話の質で見た目も分岐する。
    放置するとうんちがたまり（なかよし度の減りが早くなる）、おそうじにもコインを使う
- サーバーレスの静的サイト。**データは端末内（localStorage）にのみ保存**され、
  どこにも送信されない

## スマホで使う

1. スマホのブラウザで公開URLを開く
2. **ホーム画面に追加**（iOS: 共有ボタン→「ホーム画面に追加」/ Android: メニュー→「ホーム画面に追加」）
3. 以後はホーム画面のアイコンからアプリのように起動できる

> iOSのSafariは、長期間使っていないサイトの保存データを消すことがあります。
> ホーム画面に追加して使えばこの対象になりにくく、念のため下記のバックアップも使えます。

## データとバックアップ

- 記録は**その端末の中だけ**に保存されます（端末ごとに独立）
- 「設定」画面の **書き出し（保存）** でJSONファイルとしてバックアップ、
  **読み込み（復元）** で戻せます。機種変更のときはこの書き出し→読み込みで引っ越し
- データを初期状態に戻したいときは、ブラウザのサイトデータ削除（またはバックアップを読み込み）

## 画面

- **今日**（`index.html`）… 今日のタスク。タップで達成・ポイント加算、レベルバー、バッジ、お祝い演出。
  各タスクに炎の連続カウンター（🔥○日）と累計回数を表示。10連続でアイスクリームバッジがもらえる。
  同じタスクを複数回やった時は、タップするたびに回数が増える（1回=1タップ）。小さな「−」で1回戻せる。
  ページ上部の**デイリーボーナス**は、ギフトボックスをタップすると連続日数と抽選の演出とともにコインがもらえる
  （1日1回。翌日以降にまた受け取れる）
- **記録**（`record.html`）… ストリーク・週間/月間集計・棒グラフ・カレンダー。
  アイスクリームバッジ棚（もらった/使った/今ある数、タップで割って使える）
- **タスク履歴**（`task.html?id=`）… 各タスクの1つ下の階層。今日カードの「📈」／設定の「履歴」から開く。
  炎・累計・目標のサマリーと、達成度で色が濃くなる草・ヒートマップ風カレンダー
- **ゲーム**（`game.html`）… 「シューティング」「ペット」の入口メニューをタップして中に入る
  - シューティング：🪙30を払ってステージを選んで出撃。画面を指でなぞって移動（前後も可）、
    弾は自動。敵が落とすアイテム（💥パワー・⚡連射・❤️ライフ）を取ると強くなる。
    永続強化も購入でき、ハイスコア・累計撃墜が残る
  - ペット：コインでごはん・ごちそう・掃除（遊ぶは無料）。お世話するほど**成長ポイント**が
    貯まって進化する（餌はたくさんあげるほど早く育つ。満腹でもあげられるが伸びは小さい）。
    育て方の質で見た目が分岐し、成体まで育てたら卒業させて図鑑に記録できる
- **設定**（`parent.html`）… タスクの追加・編集・削除、名前・色の編集、バックアップ

## ポイントとコインの関係

- **XP**（レベル・バッジ用）… タスク達成の累計。減ることはない
- **コイン**（シューティング・ペットで共用）… タスク達成で貯まり、シューティングの出撃・
  永続強化、ペットのごはん・ごちそう・掃除で**消費される**。チェックを取り消すと、獲得ぶんのコインも戻る

## 開発

```bash
npm install
npm run dev        # ローカル確認用サーバー → http://localhost:3100
```

本番は GitHub Pages が `docs/` をそのまま配信する（ビルド不要）。
`master` に push すれば数分で公開に反映される。

### 構成

- `docs/` … 公開される静的サイト本体
  - `js/lib/` … ロジック（レベル計算・バッジ判定・ストリーク・タスク展開など、純粋関数）
  - `js/store.js` … localStorage への保存・読み出し（旧サーバーAPIと同じ意味論）
  - `sw.js` … Service Worker（network-first。圏外でも一度開いたページは開ける）
  - `manifest.json` … ホーム画面追加用
- `dev-server.js` … ローカル確認用の静的サーバー（本番では使わない）

### 設計メモ

- XP/レベル/バッジは達成ログ（completions）を「正」として毎回再計算するため、
  チェック・取り消しでズレが起きない
- 日付はすべて端末のローカルタイム基準（YYYY-MM-DD文字列）
